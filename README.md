# 헤븐 스텝 (Heaven Step)

마인크래프트 1.21.5 Fabric 모드입니다.
Q 키를 누르면 바라보고 있는(조준 중인) 지점에 번개가 떨어지고, 그 주변에 있는 대상은 체력이 5 하트(=10) 깎입니다.

## 기능
- Q 키 입력 시 조준 지점(최대 64블록)에 번개 소환
- 번개가 떨어진 지점 반경 3.5블록 내의 모든 생명체(몬스터, 플레이어 포함)에게 5하트 피해
- 낙뢰 지점에 전기 스파크 / 엔드로드 / 구름 파티클 연출 + 천둥소리로 화려한 연출

## ⚠️ Q 키에 대한 주의사항
바닐라 마인크래프트에서 Q는 기본적으로 "아이템 버리기" 키입니다.
게임 실행 후 옵션 → 조작 설정 → "헤븐 스텝" 카테고리에서 원하는 다른 키로 바꾸는 것을 권장합니다.

## 설치 방법
1. Minecraft 1.21.5용 Fabric Loader 설치
2. `.minecraft/mods` 폴더에 빌드된 jar 파일과 1.21.5용 Fabric API jar를 함께 넣기
3. 게임 실행 후 Q(또는 재설정한 키)를 눌러 사용
